# ATProbe 图形界面使用指南

> 面向第一次打开 ATProbe.exe 的用户。配套文档：[testcase-guide.md](testcase-guide.md)（用例怎么写）、
> [config-reference.md](config-reference.md)（atprobe.yaml / env.yaml 逐字段说明）、[cli-guide.md](cli-guide.md)（命令行）。

## 1. 启动与主窗口总览

### 1.1 启动

双击 `ATProbe.exe` 即可，无需安装 Python。窗口标题为 **「ATProbe — 串口 AT 命令自动化测试工具」**，
默认尺寸约 1200×800。启动时默认打开一个**「用例执行」**选项卡；启动约 3 秒后会在后台静默检查新版本
（有新版会弹升级对话框，失败不打扰）。

### 1.2 窗口布局

| 区域 | 内容 |
|---|---|
| 左侧深色侧栏 | 品牌头「ATProbe」+ 导航列表：**手动调试、用例执行、实时监控、环境配置**（单击任意项即打开对应页面；重复单击只是跳转到已打开的页，不会开第二份） |
| 中央选项卡工作区 | 多页签，每个页签可点 × 关闭；「执行进度」页不在侧栏里，执行时自动弹出 |
| 底部状态栏 | 左侧引擎状态灯与文字（**IDLE / RUNNING / FINISHED / ERROR**，RUNNING 时呼吸闪烁）；右侧「端口」标签与秒级时钟 |
| 顶部菜单栏 | **视图(&V)**：切换深/浅主题；**帮助(&H)**：检查更新...、打开日志目录、关于 ATProbe |

> 小提示：状态栏的「端口」标签是静态的，判断端口是否已连，看手动调试页端口下拉里名字前有没有 **●** 徽标。

### 1.3 各页职责一句话

| 页面 | 一句话职责 | 进入方式 |
|---|---|---|
| 手动调试 | 像串口助手一样手发 AT 指令、看原始响应（最常用） | 侧栏「手动调试」 |
| 用例执行 | 勾选 YAML 用例、配参数、开始/停止自动测试 | 侧栏「用例执行」（启动默认页） |
| 实时监控 | 多端口同时旁观 TX+RX 原始字节流 | 侧栏「实时监控」 |
| 执行进度 | 实时看用例/步骤/压测轮次状态 | 执行开始后自动弹出（也可在执行中从页签点回） |
| 环境配置 | 可视化编辑 env.yaml（设备指纹、服务器地址等） | 侧栏「环境配置」 |

## 2. 手动调试页（最常用，重点）

页面分左右两栏：左侧是**命令库**侧栏（见第 7 节），右侧从上到下四张卡片：
**「端口」→「文件发送」→「发送」→「响应」**。

### 2.1 连接端口（「端口」卡片）

| 控件 | 说明 |
|---|---|
| 端口下拉 | 列出系统全部串口；已连接的端口名前加 **●** 徽标 |
| 「刷新」按钮 | 重新枚举串口（插拔 USB 串口线后点它） |
| 「波特率」下拉 | 预设 9600/19200/38400/57600/**115200（默认）**/230400/460800/921600；可直接键入数值，或选末尾的「自定义…」弹输入框（允许 1 ~ 4,000,000），用过的自定义值本次会话内会记住 |
| 「帧格式」下拉 | 8N1（默认）/ 8N2 / 8E1 / 8O1 / 7E1 / 7O1 |
| 「打开端口」按钮 | 打开所选端口；成功后按钮变为红色「关闭端口」，同时波特率/帧格式两个下拉锁定不可改 |
| 流控 | 界面未提供选项，固定为无流控（none） |

- 打开失败会弹「端口错误」或「参数错误」对话框并保持未连接状态（常见原因见第 10 节）。
- 波特率非法（非整数、超出范围）会弹「波特率无效」提示，不会尝试打开。

### 2.2 第一次跑通 AT 交互（推荐步骤）

1. 设备管理器确认模组串口号（如 `COM5`）与波特率（通常 115200）。
2. 侧栏点「手动调试」；端口下拉选 `COM5`，波特率 `115200`，帧格式 `8N1`。
3. 点「**打开端口**」——按钮变为「关闭端口」即成功。
4. 发送框输入 `ATE0`（关闭回显的通用指令，用来试连），结束符保持默认 `\r\n`。
5. 点「**发送**」。响应区应立刻出现一行青色 TX `ATE0`，随后模块回 `OK`（琥珀色 RX）。
6. 看到 `OK` 即链路通；若毫无回音，依次换结束符为 `\r`、核对波特率、点「刷新」确认端口没变。

### 2.3 发送命令（「发送」卡片）

- 多行输入框占位提示为「输入 AT 指令，回车发送；Shift+Enter 换行可多行批量发送」；
  **实际发送请点「发送」按钮或按 Ctrl+Enter**（Enter/Shift+Enter 都是换行）。
- 多行内容会**按行依次发送**（空行忽略、行首尾空白去除），每行发送前先在响应区上屏一条 TX。
- 「清空」按钮只清发送框，不动响应区。
- 「结束符」下拉只有两项：`\r\n`（CR+LF，默认）与 `\r`（CR）。转义含义：`\r` = 回车 CR(0x0D)、
  `\n` = 换行 LF(0x0A)。多数模组两种都收，个别老固件只认 `\r`。
- 每次发送前会检查：未选端口弹「请先选择端口」；端口未连弹「端口 X 未连接，请先「打开端口」」。
- **测试引擎运行期间手动发送会被拒绝**，弹「发送被拒绝」提示先停止引擎——这是防止手动数据混进引擎断言。

### 2.4 响应区（「响应」卡片）

- 顶部图例 **■ TX（青）/ ■ RX（琥珀）**；每行格式：毫秒时间码 + 方向色块 + 内容，等宽字体。
- 「**HEX显示**」复选框切换 TEXT/HEX 两种显示：
  - TEXT：按 UTF-8 文本显示。`\r\n` 显示为一次换行、行尾 `\r` 不显示、连续空行保留——
    即你看到的是「人类可读」形态，**看不到** `<CR>`/`<LF>` 字样。
  - HEX：每个数据块转成一行十六进制（空格分隔）。想核对字节级换行（`0D 0A`）或结束符是否真的发出去了，
    就切 HEX。HEX 下手动发送的 TX 会显示「命令正文 + 结束符」的完整字节，可直观确认结束符配置生效。
- 「保存」按钮把响应区导出为文本（默认文件名 `atprobe-debug.log`，UTF-8 编码）；「清空」清响应区。
- 响应区是**环形缓冲，上限 10000 行**：长会话中最早的行会被自动丢弃，这是正常的内存保护，不是丢数据故障。
- 手动调试页是纯流式语义：发送只写字节、不等响应；模块回什么实时上屏，不回就不显示，没有「超时」概念。

### 2.5 文件发送（「文件发送」卡片）

把整个文件按**原始字节**写入端口（**不附加任何结束符**），适合灌配置脚本、固件包等。

| 环节 | 行为 |
|---|---|
| 「选择文件…」 | 选好后标签显示「文件名 (N 字节)」；「发送」按钮在已选文件且端口已连接时才可用 |
| 小文件（≤ 4KB） | 一次性同步发出，瞬间完成 |
| 大文件（> 4KB） | 后台线程分块发送：每块 1024 字节、间隔 5ms；显示进度条（0–100%） |
| 「取消」按钮 | 发送中才出现；点击后停止在当前块，响应区显示「已取消（已发 x/y 字节）」 |
| 发送中互斥 | 文本发送框与「选择文件…」暂时禁用，防止混流 |
| 上屏 | 无论大小，发送的字节都按块流式显示到响应区（遵循当前 TEXT/HEX 设置） |

引擎运行期间文件发送同样会被拒绝（同 2.3 的保护）。

## 3. 实时监控页

旁观一个或多个端口的**双向原始字节流**：模块回的（RX）和你这边发出的（TX）都会显示，数据与手动调试页同源。

操作路径：

1. 顶部「监控端口:」一行勾选要看的端口（可多选）；列表没刷新就点「**刷新端口**」。
2. 点「**开始监控**」（按钮变为「停止监控」）：
   - 未连接的勾选端口会**自动打开**（用默认参数 115200/8N1；打不开的端口自动跳过）；
   - 每个端口生成一个**独立子页**（子标签页），各端口数据互不混淆；
   - 一个端口都没勾会弹「请先勾选至少一个监控端口」。
3. 观察与整理：
   - 「HEX显示」勾选后，**之后到达**的数据以十六进制显示；
   - 「清空」「导出」只作用于**当前子页**；导出默认文件名 `atprobe-monitor-<端口>.log`；
   - 关闭某个子页只是清掉该端口历史显示，**监控订阅不受影响**，数据再来会重建子页。
4. 点「停止监控」结束订阅；已收到的数据保留，可回看、可导出。

关于延迟：监控页**每 200 毫秒批量刷新一次**显示（节流，防止高频数据把界面刷卡）。所以数据上屏
最多有约 0.2 秒的轻微延迟，属正常现象，不是丢数据。文本模式下 `\r\n` 归一为一次换行，设备用
单个 `\r` 刷新的进度行（如 `42%<CR>`）也会被当作换行及时显示。每个子页同样有 10000 行环形上限。

## 4. 用例执行页

从「挑用例」到「开始跑」的一站式页面。

### 4.1 用例树与筛选

| 控件 | 说明 |
|---|---|
| 「加载目录」 | 换一个用例目录；启动时默认加载配置的用例目录（默认 `examples/testcases`） |
| 「全选」/「全不选」 | 一键勾/去勾全部 |
| 「展开」/「折叠」 | 展开/折叠目录树 |
| 「标签:」下拉 | 聚合了全部用例的标签，首项「（全部）」；选某标签只留带该标签的用例 |
| 「搜索:」框 | 按「用例名/文件」实时过滤 |
| 用例树 | 三列：**用例名 / 标签 / 文件**。目录节点是**三态复选框**：勾选/半选（部分子项选中）/不选，勾选自动级联到子节点；叶子节点 = 单个用例文件。树重建（筛选后）默认全选 |

说明：目录里 `suite-` 开头的文件是套件定义，不在树中单独列出；个别 YAML 解析失败会弹
「部分用例解析失败」列出问题文件（最多预览 8 条），其余正常加载。

### 4.2 执行参数

| 参数 | 说明 |
|---|---|
| 「参与端口:」 | 本次执行使用的串口（列出系统全部可用串口） |
| 「压测阈值%」 | 0–100，默认 95；压测类用例按此成功率阈值判定 PASS/FAIL |
| 「生成报告」 | 默认勾选；去掉勾选则跑完只弹统计、不产 HTML 报告 |

### 4.3 预演、执行与停止

- 「**预演**」：只解析选中的用例 + 探测端口能否打开，**不实际执行**。弹窗汇总「将执行用例：N 个 /
  端口 X：可用或不可用 /（未实际执行）」。预演临时打开的端口用完即关，不改变你当前的连接状态。
- 「**执行选中**」：正式开跑。要点：
  - 端口若已在手动调试/监控中打开，**直接复用现有连接**（你在手动调试页设的自定义波特率有效）；
    未打开的端口会以默认参数（115200/8N1）自动打开；
  - 环境配置页开着时用页面上的当前值，否则读磁盘 env.yaml（见第 6 节）；
  - 引擎已在跑时再点会弹「已有用例正在执行中，请先停止后再开始。」；
  - 开始后状态栏变 RUNNING，「执行进度」页自动弹出。
- 「**停止**」：弹出「停止执行」三选一对话框，两种停止模式含义：

  | 按钮 | 含义 |
  |---|---|
  | 「是」 | **停止全部**：当前用例及之后所有未跑用例都不再执行 |
  | 「否」 | **仅中断当前用例**：当前用例记为 INTERRUPTED，继续跑后续用例 |
  | 「取消」 | 什么都不停，继续执行 |

- 「清空结果」：清掉执行进度页上一轮的显示。

执行完成会弹「执行完成」对话框（通过 N / 失败 M，及报告路径），并在系统默认浏览器中自动打开报告；
未勾「生成报告」时弹窗显示「（未生成报告）」。报告落在 `reports\<会话>\report.html`。

## 5. 执行进度页

**自动弹出规则**：引擎第一个进度事件到达时，若该页不存在就自动创建并激活；已存在则只把事件转发给它、
**不抢焦点**——所以执行中途你切去实时监控页不会被反复弹回。

| 区域 | 解读 |
|---|---|
| 「整体进度」进度条 | 格式「N/M 用例 P%」；开始前显示「等待开始...」，引擎结束到 100%「执行完成」 |
| 「用例进度」表 | 四列：**# / 用例 / 状态 / 耗时**。每个用例开始时新增一行、状态「运行中」；结束落定为 PASS（绿）/ FAIL（红）/ SKIPPED（黄）/ INTERRUPTED（灰），耗时以秒计 |
| 「步骤明细：」文本 | 逐条追加 `[端口] 命令 ✓/✗/⤳/⏹ 耗时ms [错误信息]`（✓ 通过、✗ 失败、⤳ 跳过、⏹ 中断）；压测用例显示为一行轮次摘要「压测 [用例]：第 n/N 轮 成功 x 失败 y 平均 z ms」；超过 2000 字自动截断头部 |

新一轮执行开始（第一个用例行到来）会自动清空上一轮显示。「清空」按钮手动清。

## 6. 环境配置页

**env 是什么**：记录「这台设备、这次测试环境的事实」——设备指纹、服务器地址、端口、账号等。
用例里以 `{{组名.参数名}}` 引用（写法详见 testcase-guide.md）。env 与用例分离，换设备只改 env 不动用例。

页面结构：顶部「加载文件」「保存」「＋新建组」按钮；下方每个组一张卡片，组内一行一个参数输入框，
每张卡片末尾有「＋参数」按钮。参数名含 password / pass / secret（不区分大小写）的输入框自动**脱敏显示**
（圆点），可正常编辑。

**「所见即所跑」语义**（核心）：

- 在输入框里每敲一个字符，改动**立即进入内存中的环境配置**——不需要点「保存」。
- 但它生效的时机是**下一次点「执行选中」**：正在跑的执行不受影响，用的是它开始时的快照。
- 执行时若该页开着：以页面当前值为准；若有未保存改动，会先**静默写盘**（不弹窗）再执行。
- 该页关着时：执行从磁盘读 env.yaml（配置路径默认 `examples/env.yaml`，不存在时回退内置示例；
  读取失败会弹「环境配置加载失败」警告而不是静默忽略）。

**保存与 dirty 状态**：

- 「保存」显式写盘；从未保存过会先弹另存对话框（默认名 `env.yaml`），成功弹「已保存」。
  写盘失败（如目录只读）弹「保存失败」，但内存值仍会在下次执行时生效。
- 「有未保存改动」（dirty）的判定是与磁盘文件做**结构化比对**：`port: 21`（数值）与表单里的
  `"21"`（文本）视为相同，不会误报。
- 带 dirty 状态关闭本页签时，会弹「未保存的环境配置」三选一：**保存 / 丢弃 / 取消**（取消 = 不关页）。

## 7. 命令库

三层树：**项目 → 功能组 → 命令**（如「N58 → 网络注册 → AT+CEREG?」），存在 YAML 文件里，随软件自带示例。

### 7.1 命令库面板（手动调试页左侧）

- 顶部「**管理**」「**刷新**」按钮 + 当前库文件名。
- **单击命令叶子 = 立即发送**到手动调试页当前端口（等同在发送框发出，用当前结束符设置）；
  单击项目/功能组节点只是展开/收起。
- 面板里增删改只走**右键菜单**（发送界面不响应双击，防止连发时误触修改弹窗）：

  | 右键对象 | 菜单项 |
  |---|---|
  | 空白处 | 新增项目 |
  | 项目节点 | 重命名 / 新增功能组 / 删除项目 |
  | 功能组节点 | 重命名 / 新增命令 / 删除功能组 |
  | 命令叶子 | 修改 / 删除命令 |

- 面板上的改动**即时落盘**。删除项目/功能组会弹确认（子节点一并删除）；删除命令直接执行。
- 空库时树中显示提示「（空，点击「管理」或右键添加命令）」。

### 7.2 「命令库管理」对话框（点「管理」）

- 顶部「＋项目」「加载…」「另存为…」+ 文件名；树标题为「项目 / 功能 / 命令（双击修改 · 右键增删）」。
- **双击任意节点就地修改**（对话框里可以双击，与面板不同）；右键增删同上；
  项目/功能组行内还有 **＋** 小按钮，直接在其下新增功能组/命令。
- 对话框编辑的是**工作副本**：点「取消」全部丢弃；点「**确定（保存）**」才统一写盘。
- 「加载…」是把别的库文件的**内容导入当前库**（保存目标不变）；「另存为…」才是切换保存目标文件。

## 8. 主题与外观

- 默认**浅色**主题；菜单 **视图(&V) → 切换深色主题**（勾选项）切到深色，勾掉或点「切换浅色主题」切回。
- 选择会被记住（写入系统设置），下次启动沿用当前外观；两套主题下 TX/RX、状态色语义一致。
- 数据区（响应、监控、命令）始终使用等宽字体，便于核对字节与命令。
- 帮助(&H) 菜单还提供：**检查更新...**（手动检查新版，可一键升级）、**打开日志目录**（定位
  `atprobe.log`，排查问题时先看它）、**关于 ATProbe**（版本号与项目地址）。

## 9. 常见操作流程串讲：从连接到出报告

以「新设备到手 → 跑一轮回归 → 拿到 HTML 报告」为例：

1. **连设备**：插上串口，手动调试页选端口/波特率 → 「打开端口」→ 发 `ATE0` 看到 `OK`。
   【截图位：手动调试页，端口卡片与响应区中的 ATE0/OK】
2. **配环境**：环境配置页核对设备指纹、服务器地址等参数（改完不用点保存，下次执行自动生效）。
   【截图位：环境配置页的分组表单】
3. **挑用例**：用例执行页「加载目录」选用例目录（或用默认目录），用「标签:」「搜索:」缩小范围，
   在树上勾掉不想跑的（目录节点半选 = 部分选中）。
   【截图位：用例树，展示三态复选框】
4. **预演**：点「预演」确认「用例 N 个 / 端口可用」。
5. **执行**：核对「参与端口:」「压测阈值%」「生成报告」→ 点「执行选中」。状态栏变 RUNNING，
   执行进度页自动弹出，逐用例、逐步骤滚动刷新。
   【截图位：执行进度页，表格与步骤明细】
6. （可选）**旁观**：切到实时监控页看原始字节流；中途需中断点「停止」选范围。
7. **收报告**：跑完弹「执行完成」（通过/失败统计），浏览器自动打开
   `reports\<会话>\report.html`；失败步骤可在报告与执行进度页的步骤明细中对照定位。

## 10. 常见问题（FAQ）

**Q1：点「打开端口」弹「端口错误」，打不开？**
端口被其他程序占用是最常见原因：串口助手、另一个 ATProbe 实例、设备厂商的调试工具。关掉它们再点
「刷新」重试；USB 转串口线插拔后端口号可能变化，重新选一次。

**Q2：执行用例时提示端口失败/被占用？**
执行会复用 GUI 已打开的连接，但如果该端口被**本软件之外**的程序占着，自动打开就会失败并弹
「端口错误」。先关占用程序；另外执行期间手动发送/发文件会被拒绝（弹「发送被拒绝」），这是防止
手动数据污染引擎断言的保护，停掉引擎即可恢复手动操作。

**Q3：为什么看不到 URC（如 `+CEREG: 1` 主动上报）？**
手动调试页和实时监控页显示的都是**原始 RX 字节流**，URC 行会和普通响应一样原样上屏——不会被过滤掉
（urc_filter 只影响引擎执行时的响应断言剥离，不影响页面上屏）。看不到时按顺序检查：端口是否已打开、
响应区是否刚被「清空」、数据是否为不可见字节（切「HEX显示」看十六进制）、监控页是否有约 0.2 秒的
正常节流延迟。

**Q4：响应里到底有没有回车换行？**
TEXT 模式下 `\r\n` 只表现为换行、行尾 `\r` 不显示，所以肉眼分不出 `\r` 与 `\r\n`。要核对字节级换行，
勾「HEX显示」：回车是 `0D`、换行是 `0A`；HEX 下你发出的命令也会连带结束符字节一起显示。

**Q5：响应区/监控子页最早的内容不见了？**
两处都是 10000 行环形缓冲，超限自动丢弃最旧行，属正常保护。需要留档请及时点「保存」/「导出」。

**Q6：发送框按回车没反应？**
当前版本请点「发送」按钮或按 **Ctrl+Enter** 发送；Enter/Shift+Enter 是换行（可借此一次贴多条命令批量发送）。

**Q7：波特率下拉里没有我要的值？**
下拉可直接键入数字，或选「自定义…」输入（1 ~ 4,000,000）；输入过的值本次会话会留在候选里。

**Q8：环境配置改了怎么没生效？**
编辑即时进入内存，但只在**下一次执行**时被读取——正在跑的执行不会中途换环境。确认执行时环境配置页
是开着的（页面开=用页面值；页面关=用磁盘 env.yaml），两者不一致时建议保持开着。

**Q9：执行好像卡住/弹「执行异常」？**
引擎异常会弹「执行异常」并附日志文件路径；用 帮助(&H) → 打开日志目录 找 `atprobe.log` 排查，
常见是用例等待超时过长或串口中途拔出。

**Q10：报告在哪里？**
默认 `reports\<会话>\report.html`（会话名 = 日期时间 + 随机后缀）；执行完成时会自动用系统浏览器打开。
未勾「生成报告」则不生成，弹窗会注明「（未生成报告）」。
